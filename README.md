# Incremental Predictive Value of Knowledge-Guided Immune Transcriptomic Features for Immunotherapy Response in Urothelial Carcinoma

This study quantifies whether pretreatment immune transcriptomic signatures add
predictive value for response to PD-1/PD-L1 checkpoint inhibitors in metastatic urothelial
carcinoma, beyond clinical variables and standard biomarkers (TMB, PD-L1 IHC) — and how
that value changes as additional biomarker information is available (the biomarker-
richness gradient). A knowledge-guided signature panel (Block K, 8 prespecified immune
signatures) is compared against unconstrained data-driven feature selection (elastic net),
at both the predictive-performance and gene/pathway-stability level. Findings are
externally validated in an independent cohort.


## Data availability

No data is included in this repository. Both datasets used are public but must be
obtained directly from their original sources; `.gitignore` keeps all data and model
outputs out of version control, and this should stay that way.

- **IMvigor210** (training/development cohort, n=298 response-evaluable) — publicly
  available via the `IMvigor210CoreBiologies` R package (Mariathasan et al., *Nature* 2018).
- **GSE176307 / UNC-108** (external validation cohort, n=87 evaluable) — publicly
  available via the Gene Expression Omnibus (GEO), accession
  [GSE176307](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE176307). Requires the
  series matrix file, the Salmon-quantified TPM gene matrix, and the Omniseq sample name
  key, all available from the same GEO accession.
- **MSigDB Hallmark gene sets** (`h.all.v7.0.symbols.gmt`) — used for pathway enrichment,
  publicly mirrored via the Broad Institute's `ssGSEA2.0` GitHub repository.
- **MCP-counter marker genes** — used for 5 of the 8 K signatures, from Becht et al.,
  *Genome Biology* 2016.

Expected local layout (not tracked in this repo):
```
data/
  raw/            expression_counts.csv, feature_metadata.csv, sample_metadata.csv,
                  genes.txt (MCP-counter), human_gene_signatures_long.csv (Mariathasan),
                  h.all.v7.0.symbols.gmt (Hallmark)
  processed/      analysis_cohort.csv, signature_scores.csv, etc. (generated by scripts)
  external/       GSE176307 series matrix, TPM matrix, sample key (generated/downloaded)
```

```

  elastic_net.py            variance-floor filtering, elastic net fitting, stability metrics
  subgroup.py                subgroup/interaction test helpers
  pathway_enrichment.py     Hallmark hypergeometric + rank-based enrichment testing
  external_validation.py    GSE176307 harmonization, frozen-model utilities
  feature_importance.py     standardized ridge coefficient extraction

scripts/
  run_data_audit.py                                  Sample/gene/duplicate/missingness audit
  run_signature_scoring.py                            Computes all 8 K signature scores
  run_primary_model.py                                Primary comparison: C+B vs. C+B+K
  summarize_primary_results.py                        Summarizes primary + gradient results
  assess_significance.py                              Wilcoxon/paired-t/CI, primary + sensitivity
  run_redundancy_gradient.py                          Full gradient: C, C+B, C+B+R (+/- K)
  run_elastic_net_stability.py                        Elastic net fold-safe stability pipeline
  merge_elastic_net_results.py                        Merges elastic net vs. C+B+K comparison
  check_gene_selection_scale.py                        Background pool size, chance-baseline check
  map_elastic_net_genes.py                             Maps selected genes (Entrez -> symbol)
  run_pathway_enrichment.py                            Hallmark pathway enrichment (both methods)
  check_K_B_correlation.py                              K signature x B biomarker correlation
  run_sensitivity_CRPR_vs_PD.py                        Sensitivity cohort (SD excluded), C+B level
  run_redundancy_gradient_SENSITIVITY_EXPLORATORY.py    Sensitivity cohort, full gradient
  compare_primary_sensitivity.py                        Compares primary vs. sensitivity results
  run_subgroup_redundancy.py                            Subgroup CV by PD-L1 IC level
  run_interaction_test.py                                K x IC-level formal interaction test
  run_component_ablation.py                              Drop-one-signature ablation within K
  run_feature_importance.py                              Standardized coefficients, C+B vs. C+B+K
  parse_gse176307_clinical.py                            Parses GSE176307 series matrix -> clinical CSV
  run_external_validation.py                             Frozen-model external validation (2 levels)
  build_table1.py                                        Baseline characteristics table
```

Every script in `scripts/` adds the repository root's `src/` to `sys.path` and imports the
relevant module(s) from there; run all scripts from the repository root, not from inside
`scripts/`.

## Running

Scripts are listed in the order they depend on each other's outputs. All commands assume
you are in the repository root with the expected `data/raw/` layout in place.

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 1. Data audit and preprocessing
python3 scripts/run_data_audit.py
python3 scripts/run_signature_scoring.py

# 2. Primary analysis and redundancy gradient
python3 scripts/run_primary_model.py
python3 scripts/run_redundancy_gradient.py
python3 scripts/summarize_primary_results.py
python3 scripts/assess_significance.py

# 3. Data-driven comparator (elastic net) and stability analysis
python3 scripts/run_elastic_net_stability.py
python3 scripts/merge_elastic_net_results.py
python3 scripts/check_gene_selection_scale.py
python3 scripts/map_elastic_net_genes.py
python3 scripts/run_pathway_enrichment.py
python3 scripts/check_K_B_correlation.py

# 4. Sensitivity analysis (SD excluded, CR/PR vs. PD)
python3 scripts/run_sensitivity_CRPR_vs_PD.py
python3 scripts/run_redundancy_gradient_SENSITIVITY_EXPLORATORY.py
python3 scripts/compare_primary_sensitivity.py

# 5. Subgroup, interaction, and ablation analyses
python3 scripts/run_subgroup_redundancy.py
python3 scripts/run_interaction_test.py
python3 scripts/run_component_ablation.py
python3 scripts/run_feature_importance.py

# 6. External validation (requires GSE176307 files in data/external/)
python3 scripts/parse_gse176307_clinical.py
python3 scripts/run_external_validation.py

# 7. Manuscript Table 1
python3 scripts/build_table1.py
```

## Verification

Cross-validation folds are generated once (`cv_splits.pkl`) and reused by every script
that compares feature blocks on the same cohort, so all comparisons in the primary
analysis and redundancy gradient share identical outer/inner splits. All preprocessing
(imputation, scaling, elastic net's variance filter) is fit within outer training folds
only, never on the full dataset, to prevent leakage.

Specific checks performed during development, documented in the corresponding script or
commit history:
- Elastic net solver convergence tracked per fold (`elastic_net_convergence.csv`);
  hyperparameter grid was narrowed after an initial run showed non-convergent folds at
  higher `C` values.
- Background gene pool size for elastic net (~18,300 of 31,286 genes post variance-floor)
  and observed gene-level selection stability (mean Jaccard 0.227) were checked against
  the random-chance baseline for draws of that size from that pool (~0.010), confirming
  selection reflects genuine reproducible structure rather than noise
  (`check_gene_selection_scale.py`).
- External validation models are frozen on IMvigor210 only (hyperparameter selection and
  final fit) before GSE176307 is loaded; no component of external evaluation informs
  model fitting.
- Signature-to-gene mappings (Hallmark, MCP-counter) were checked for gene coverage
  against the expression panel before being trusted, with any unmapped genes explicitly
  reported rather than silently dropped.
